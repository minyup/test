# 키 없이 도는지 확인 (LB-133)

`SPEC.md` 8.4절 — 저장소를 새 폴더에 받아 환경변수와 API 키를 하나도 주지 않은 채
설치·실행만 했을 때 대시보드가 뜨고 300건이 화면에 나타난다 — 를 확인한 기록이다.

작업 중인 폴더에서 확인하면 이미 만들어져 있는 `node_modules`나 내 PC에 남아 있는
환경변수 덕에 도는 것과 구분되지 않는다. 그래서 **새 폴더에 clone해서** 확인했다.

## 한 일

```
git clone --branch dev <저장소> <새 폴더>
cd <새 폴더>/issue-radar
npm install          # 105개 패키지, 42초
npm run build        # 통과
npx next start --port 3007
```

`.env` 파일은 만들지 않았고 환경변수도 주지 않았다. clone한 트리에 `.env`가 한 개도
없다는 것은 `git ls-files`로 함께 확인했다.

## 결과

| 확인 항목 | 기대 | 실제 |
|---|---|---|
| 대시보드가 뜨는가 | 뜬다 | 뜬다 (`디스플레이 시장 이슈 조기 감지`) |
| 언급 건수 | 300 | 300 |
| 원문 목록 | 300건 중 20건 | 300건 중 20건 |
| 추세 그래프 x축 눈금 | 30 | 30 |
| 분포 차트 조각 | 7 | 7 |
| 데이터 오류 화면 | 뜨지 않는다 | 뜨지 않는다 |

설치·빌드·실행 어느 단계에서도 키를 묻지 않았고, 화면 어디에도 오류가 뜨지 않았다.
